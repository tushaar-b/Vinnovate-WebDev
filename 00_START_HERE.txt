LOCKED DECISIONS
- React + Vite + TypeScript + Tailwind CSS; FastAPI + SQLAlchemy + Alembic; PostgreSQL; Redis + RQ worker; Playwright/Chromium; Pillow and difflib.
- Docker Compose for Postgres + Redis; frontend/backend run locally. Worker and scheduler as separate local processes.
- Single-user LOCAL DEMO: no auth in v1; never claim multi-tenant security. Avoid internet exposure.
- Poll-based scheduler and shared-fetch optimization at URL/config level, where feasible.
- No LLM dependency, no paid services, no external API keys needed for core demo.
- Baseline screenshot+text; text normalization and hashing; errors not versions; versions on hash changes; text/visual diff; selector picker; retry; per-domain politeness; Discord/Telegram optional (email stretch).
- Demo against an INCLUDED local fixture webpage; real public websites only when allowed and not blocked.

DEFINITION OF DONE
User adds monitored URL, manually checks, sees statuses and versions, changes fixture, checks again, sees text+visual diff, filters noise, can select region, receives optional webhook alert exactly once per change, and automatic scheduler performs checks. All runnable with one documented setup and reproducible smoke tests.
